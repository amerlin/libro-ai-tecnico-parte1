# Quaderno AI — Numero 1

## Concetti, strumenti e percorsi pratici per lo sviluppo software con AI

**Un percorso operativo per costruire applicazioni .NET con l'intelligenza artificiale.**

L'intelligenza artificiale sta cambiando il modo in cui scriviamo software, ma tra chi la usa "a caso" e chi la integra con metodo c'è una differenza enorme. Questo libro ti porta dalla teoria ai fatti: imparerai a costruire **MCP server completi in .NET 10**, a dare ai tuoi agenti memoria e dati con **Entity Framework Core**, a dirigere lo sviluppo con le **specifiche** e a **personalizzare gli agenti di codifica** con istruzioni, skill e plugin.

Non è una raccolta di prompt: è un manuale operativo, con codice funzionante, esempi end-to-end e le trappole da evitare, pensato per chi sviluppa davvero.

## Cosa imparerai

- **Costruire MCP server completi in .NET 10** — tool, risorse, prompt, trasporti `stdio` e HTTP, lifecycle, sicurezza e test con l'MCP Inspector;
- **Modellare dati e query con EF Core** — dominio, migrazioni, il pattern `IDbContextFactory` e i primitivi avanzati del protocollo;
- **Applicare lo spec-driven development** con GitHub Spec Kit — specificare, pianificare, scomporre e convergere con un processo riproducibile;
- **Estendere gli agenti di codifica** — istruzioni con attivazione per pattern, standard Agent Skills, agenti con strumenti limitati, plugin;
- **Migrare a .NET da PHP, Python, Node.js e Java** — assessment, pianificazione incrementale e mappatura delle tecnologie.

## Contenuti del volume

1. **Model Context Protocol: fondamenti e implementazione di un MCP Server in .NET 10** — architettura, primitivi, JSON-RPC, ecosistema .NET e il tuo primo server.
2. **Un MCP Server con Entity Framework Core** — dati, query e primitivi avanzati, con un dominio catalogo prodotti completo.
3. **GitHub Spec Kit: sviluppo guidato dalle specifiche** — workflow completo con esempi in C# e integrazione CI/CD.
4. **Istruzioni, skill, agenti e plugin: estendere un agente di codifica** — mappa delle cartelle per Copilot, Claude Code, Cursor, Gemini CLI, Codex e DeepSeek.
5. **Migrare a .NET da altri linguaggi e piattaforme** — architettura ASP.NET Core, EF Core, sicurezza, testing e un caso pratico completo.

## A chi è rivolto

A sviluppatori .NET che vogliono integrare l'AI nel loro lavoro quotidiano, a chi ha già provato i copilot e vuole andare oltre, e a chi arriva da PHP, Python, Node.js o Java e vuole muovere i primi passi — concreti — nel mondo .NET. Non servono conoscenze pregresse di MCP o di AI: ogni concetto è introdotto da zero, ma sempre con l'obiettivo di arrivare a codice che funziona.
